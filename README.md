# Foyer Management Platform

A microservice-based web application for managing job applications and housing services (foyer).

## 📁 Project Structure

- `ApiJob/` – **API Gateway** (handles routing and central access to services)
- `MsFoyer/` – Microservice for housing (foyer) features
- `eurekaMs/` – Eureka service registry for microservices
- `foyer-front/` – Front-end built with [Angular 16]
- `docker-compose.yml` – Manages containerized deployment

## 🚀 Getting Started

1. Clone the repository
2. Run `docker-compose up` to start all services
3. Access the front-end at `http://localhost:5200`

## 📦 Tech Stack

- Java / Spring Boot (back-end)
- Angular (front-end)
- Eureka (service registry)
- Docker & Docker Compose
- Spring Cloud Gateway : API Gateway
